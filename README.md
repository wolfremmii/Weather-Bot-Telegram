# 🌤 WeatherCheckBot

A Telegram bot that shows the current weather in any city around the world. Supports both English 🇬🇧 and Russian 🇷🇺 languages. Powered by the OpenWeather API.
## Features

- Language selection on start (English or Russian)
- Accepts city names in both Russian and English
- Shows detailed weather info: temperature, description, humidity, and wind speed
- Handles common errors like "City not found" or network issues

## Installation

1. **Clone the repository** or download `WeatherCheckBot.py` + `requirements.txt`.
2. Install dependencies:
```bash
pip install -r requirements.txt
```
3. Add your tokens to WeatherCheckBot.py
```
BOT_TOKEN = 'Your Telegram Bot Token'
OWM_API_KEY = 'Your OpenWeather API Key'
```
BOT_TOKEN: Get your bot API token from BotFather, it's simple.
OWM_API_KEY: 
1. Register on this website - https://openweathermap.org/
2. After logging in, open the API Keys page. You will already have one key generated by default (for example, abc123...).

## Launch
Run the bot with the command:
```bash
python main.py
```
